Dibujos originales para pintar en casa o en clase. Tu progreso se guarda en este navegador.

Cómo se juega

  • 🪣 Relleno: toca una zona del dibujo y se pinta con el color elegido. Si arrastras, pintas varias zonas seguidas.
  • 🖌️ Pincel: dibuja a mano alzada y cambia el grosor con el deslizador.
  • 🧽 Borrador: pasa por encima de un trazo para quitarlo, o toca una zona pintada para dejarla como estaba.
  • ⬆️ Tus dibujos: pulsa «Subir mi dibujo», arrastra una imagen PNG o JPG, o pégala con Ctrl+V. Se colorean igual que las láminas: el relleno respeta las líneas negras y puedes ajustar la tolerancia si tu imagen tiene sombras.
  • ↶ Deshacer y ↷ Rehacer (Ctrl+Z, Ctrl+Y) para corregir sin miedo.
  • Puedes descargar tu lámina e imprimirla cuando quieras. El dibujo se guarda solo: cierra la página y sigue pintando otro día.
